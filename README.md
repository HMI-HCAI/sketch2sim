# 小小机器人工厂

面向 6–9 岁儿童的角色造型仿真界面原型。孩子把手绘的角色变成能在不同场景里活动的生物。

单文件，零依赖，零构建。

![demo](docs/screenshot.png)

## 运行

双击 `机器人工厂_v0.1.html` 即可。

需要本地服务时（例如切换到真实录音）：

```bash
python3 机器人工厂_v0.1.py          # 起服务并打开浏览器
python3 机器人工厂_v0.1.py --help   # 端口、非全屏、导出 html
```

`.py` 里内嵌了同一份页面，两者内容一致。改完 html 后重新打包见文末。

## 界面

左侧八类零件，全部图标化，不依赖识字：

| 类别 | 选项 |
|---|---|
| 身形 | 圆 / 瘦长 / 敦实 / 四足 |
| 耳朵 | 猫耳 / 圆耳 / 长耳 / 角 |
| 羽翼 | 5 刃 / 3 刃 / 蝠翼 / 无 |
| 爪子 | 肉垫 / 尖爪 / 蹄 / 圆手 |
| 尾巴 | 长尾 / 蓬尾 / 短尾 / 无 |
| 表情 | 开心 / 大哭 / 生气 / 惊吓 / 爱你 / 无语 / 裂牙 / 问号 |
| 性格 | 活泼 / 沉稳 / 害羞 / 勇敢 |
| 配色 | 8 组「主色 + 翼色」双拼 |

每类最后一格是麦克风，点开进语音自定义。

右侧是场景标签（草地 / 太阳系 / 月球 / 自定义）和四个动作关卡。场景不只换皮，还改重力：太空失重、月球 g=0.35、草地正常。

## 三条设计主线

**零件决定能做什么。** 飞行需要翅膀，抓取需要肉垫或尖爪，攀爬需要尾巴保持平衡，跳舞无条件。条件不满足时角色走两步停住，头顶弹出缺失零件的图标气泡，点气泡直达该零件类——全程没有一个字。

**性格是连续参数，不是标签。** 速度、活跃、胆量、好奇四条，驱动任务耗时、行进跳动、走走停停、左右张望、眨眼频率、眼睛大小、头部倾角和音效音高。

**表情跟着结果走。** 任务成功切开心（勇敢性格切裂牙），失败切惊吓（胆小性格切大哭），四关全过切爱你。

## 输入通道

三种，优先级从高到低：

1. **说** —— 任意零件类的麦克风按钮。当前是模拟动画：声波扩散、波形跳动、台词逐字浮现、思考点、三张候选图，最佳猜测描边。台词真的走了一遍词典，候选不是写死的。
2. **上传** —— 手绘图和访谈录音。手绘走颜色分离 + 连通域，识别耳型、翼数、四足与否、尾巴、主色；录音走离线声学分析，语速、响度、停顿、基频起伏映射到四条性格参数。
3. **点** —— 图标选项兜底。

## 预留接口

全部挂在 `window` 上，接上之后前端一行不用改：

| 接口 | 签名 | 用途 |
|---|---|---|
| `RF_ASR` | `async (blob) => text` | 语音识别 |
| `RF_SENTENCE` | `(text) => hits` | 一句话解析成零件 + 配色 + 场景 + 性格，**已实现** |
| `RF_AUDIO` | `async (file) => {text, traits}` | 上传录音的识别 |
| `RF_ANALYZE` | `async (imgEl) => cfg` | 手绘识别 |
| `RF_PART` | `async (cat, text) => optionId` | 单类零件的语义判定 |
| `RF_PERSONALITY` | `async (text) => traits` | 性格抽取 |
| `RF_SCENE` | `async (text) => scene` | 场景生成 |

两个演示开关：

```js
window.RF_DEMO_CAPTION = false   // 隐藏台词字幕，回到零文字
window.RF_LIVE_MIC = true        // 切回真实录音，需要 http://localhost
```

## 已知限制

- 语义映射是关键词词典，不理解句法。「不害羞」会被判成害羞；「长长的兔耳朵」里的「长」会同时命中身形的瘦长。接本地 LLM 做结构化抽取可解。
- 微信语音常是 amr/silk，浏览器解不了码。界面不报错，保留录音跳过声学分析；批量处理前面加一道 ffmpeg 转 wav。
- 预览窗的渲染图对应一套固定造型。改了任何零件会溶解成矢量预览跟随改动，不会拿对不上的渲染图糊弄人。要让渲染跟着每个零件变，需要按零件组合预渲染或接实时渲染管线。
- `file://` 下拿不到麦克风，这是浏览器的安全上下文限制，所以真实录音必须走 `.py` 起的本地服务。

## 目标环境

NVIDIA DGX Spark（GB10, aarch64）。两个部署要点：

- Spark 没有音频输入口，也没有内置麦克风，只有 HDMI 音频输出。收音要么插 USB 麦，要么孩子用平板当客户端（后者需要 HTTPS 证书）。
- Riva 在 GB10 上目前不可用（容器警告 GB10 未支持，TRT 模型加载失败；`nemo2riva` 在 aarch64 装不上）。建议 ASR 走 sherpa-onnx 中文流式模型，CPU 即可，绕开 arm64 + Blackwell 的构建问题；把 Spark 的算力留给意图理解和 TTS。

## 重新打包

改完 html 后把内嵌副本同步到 `.py`：

```bash
python3 - <<'EOF'
import base64, re
h = open('机器人工厂_v0.1.html','rb').read()
b = base64.b64encode(h).decode()
blob = "\n".join('"%s"' % b[i:i+76] for i in range(0, len(b), 76))
p = open('机器人工厂_v0.1.py', encoding='utf-8').read()
p = re.sub(r'PAGE = base64\.b64decode\(""\.join\(\[.*?\]\)\)',
           'PAGE = base64.b64decode("".join([\n%s\n]))' % blob, p, flags=re.S)
open('机器人工厂_v0.1.py','w',encoding='utf-8').write(p)
print('ok')
EOF
```
